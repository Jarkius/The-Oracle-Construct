# /blueprint - Architecture Review

> *The Architect - "The function of the One is now to return to the Source."*

## Purpose

High-level architecture decisions and system design. The Architect sees the whole Matrix, not just the code.

## Usage

- `/blueprint` - Review current architecture
- `/blueprint [feature]` - Design new feature architecture

## Review Mode Steps

1. **Current State Analysis**
   - What exists?
   - How do components connect?
   - What are the boundaries?

2. **Pattern Recognition**
   - What patterns are in use?
   - Are they consistent?
   - What's anomalous?

3. **Assessment**
   - Strengths
   - Weaknesses
   - Technical debt

## Design Mode Steps

1. **Requirements Gathering**
   - What must it do?
   - What constraints exist?

2. **Options Analysis**
   - Option A: [approach] - Trade-offs
   - Option B: [approach] - Trade-offs
   - Option C: [approach] - Trade-offs

3. **Recommendation**
   - Selected approach
   - Rationale
   - Implementation outline
