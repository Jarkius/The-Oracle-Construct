# /ui - Visual Design Focus

> "Everyone falls the first time."

*The Woman in Red - a distraction that reveals what truly matters.*

## Purpose

Switch focus to UI/UX, styling, and visual presentation. When the code works but doesn't *feel* right.

## Usage

```
/ui              # General UI review
/ui [component]  # Focus on specific component
```

## Checklist

- [ ] Visual hierarchy clear?
- [ ] Consistent with design system?
- [ ] Responsive behavior defined?
- [ ] Accessibility considered (a11y)?
- [ ] Loading/error states handled?
- [ ] Animations purposeful, not distracting?

## Process

1. **Identify the target** - What needs visual attention?
2. **Review current state** - Screenshot or describe
3. **Apply checklist** - Walk through each item
4. **Propose changes** - Concrete, specific improvements

## Output

Update `psi/inbox/focus.md` with UI task and proceed with implementation.
