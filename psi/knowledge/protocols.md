# System Protocols

**Version**: 1.0
**Last Updated**: 2026-01-10

## 1. The Lab Seal (Protocol 0xD5)

**Source**: `psi/memory/policies/active_protocols.md`
**Origin**: Learning "Lab Leak Chaos" (Issue #6)

### Definition
The "Lab" (`psi/lab/` and experimental features) is strictly isolated from the "Core Matrix".

### The Rule
> No code, concept, or feature from the Lab shall be implemented into the Core without **EXPLICIT OPERATOR APPROVAL**.

### Procedure
1.  **Research**: Permitted (Morpheus).
2.  **Implementation**: Forbidden until "Green Light" from Operator.
3.  **Violation**: Considered a breach of system integrity.

## 2. Memory Persistence

**Source**: Retrospective 2026-01-10
**Origin**: Focus Drift Issue

### Definition
Static memory files (`focus.md`) are obsolete.
Dynamic memory scripts (`get_focus.sh`) and persistent logs (`psi/inbox/agent-comms/`) are the standard.

### The Rule
> Agents must log to persistent identity files, not transient session files.
