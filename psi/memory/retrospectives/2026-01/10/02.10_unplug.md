# Retrospective: Voice Queue V2 (Python Evolution)
**Date**: 2026-01-10
**Focus**: Robust Voice Architecture
**Protocol**: 0x01 (Inspiration) Activated

## 1. The Achievement
We successfully migrated from a file-locking system to a **Centralized Python Voice Server**.
-   **Queue**: In-Memory, Thread-Safe, Infinite Patience.
-   **Stability**: Handled "Burly Brawl" (20 concurrent requests) with zero crashes.
-   **Crisis Mode**: Implemented `--panic` for immediate concurrent playback.

## 2. The Learnings
-   **Process Management**: `nohup` on MacOS requires explicit `< /dev/null` redirection to avoid TTY suspension (`SIGTTOU`).
-   **Zombie Processes**: Killing the parent server does not always kill child `afplay` processes. `killall` is a necessary hygiene step.
-   **User Feedback**: "Inspiration > Request". The system was too passive. Protocol 0x01 now mandates proactive suggestion.
