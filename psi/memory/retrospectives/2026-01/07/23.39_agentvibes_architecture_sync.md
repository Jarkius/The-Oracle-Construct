## AI Diary

I assumed the `/agent-vibes:update` command would work with `agent-vibes`, but learned the package is actually `agentvibes` (no hyphen). This is a common naming convention issue that caught me off guard - the slash commands use hyphens but the npm package doesn't. This discrepancy exists because the slash command system and npm registry have different naming conventions.

I was confused about where Piper was installed until I traced the symlink chain from `~/.local/bin/piper` to the pipx virtual environment. The fact that it was installed via pipx rather than as a native binary wasn't obvious from the file path alone. I had to use `file` and `ls -la` to understand the installation method.

I expected the native Piper binary would be faster and worth the migration effort, but got library dependency errors because the macOS aarch64 release is actually x86_64 (mislabeled). The Rosetta emulation layer couldn't handle the missing dylib references properly, causing the process to hang. This taught me that precompiled binaries for macOS often have complex dependency chains that Python packages handle automatically.

The parallel world architecture was genuinely surprising. I didn't anticipate that `.claude/agents/` files would have voice metadata that was completely disconnected from the actual TTS system. The `voice: Reed (American Male)` in `neo.md` was just documentation - the real config lived in `voices.json`. This kind of drift happens naturally in evolving systems, but it creates confusion. Synchronizing them maintains both human-readable documentation and operational correctness.
