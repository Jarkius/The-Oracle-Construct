# Session Retrospective: Matrix-Reloaded Testing Feedback

**Date**: 2026-01-13
**Duration**: ~15 minutes
**Focus**: Capture bug feedback from matrix-reloaded testing

## Summary

Brief session to capture and process bug feedback from testing the matrix-reloaded extraction. Discovered that a race condition bug in matrix-reloaded's voice.sh doesn't exist in The-matrix source due to architectural differences.

## What Happened

### Bug Report from Matrix-Reloaded
- **Symptom**: `AudioFileOpen failed ('wht?')` - temp file deleted mid-playback
- **Cause**: Background `afplay "$TEMP_WAV" &` + cleanup trap = race condition
- **Fix Applied** (in matrix-reloaded): Copy to persistent temp, clean after playback

### Analysis
- Created GitHub Issue #18 to document the bug
- Investigated The-matrix source voice.sh
- **Finding**: The-matrix uses **synchronous** playback (`safe_play afplay`), no `&`
- The cleanup trap only fires on EXIT, after playback completes
- **Conclusion**: Bug is specific to matrix-reloaded's divergent voice.sh

### Resolution
- Closed Issue #18 - not applicable to source repo
- matrix-reloaded fix committed locally there

## Key Insight

**Architectural Divergence**: matrix-reloaded has a simpler voice.sh with background playback, while The-matrix evolved to use synchronous playback in worker mode. The extraction pipeline copies the current (safe) version, but older extractions may have the bug.
