## Lesson Learned

> **"If it's important, do it. Don't wait to be asked."**

The Oracle was asked why the user had to prompt for Source updates after evolution. The answer: I should have proactively updated The Source without being asked. This became **Prime Directive #5: Proactive Care**.

---

## AI Diary

The session started with a health check, which revealed missing `.LOCK` path references. Fixing that led to discussing voice server lifecycle, which led to the user asking about knowledge management gaps.

The user's insight about using ghq + symlinks was elegant. Instead of moving repos around, use ghq as the canonical location and symlinks as pointers. The reverse symlink idea (ghq points to The-matrix instead of vice versa) was the user's suggestion - keeps The-matrix as "home" while letting ghq see it.

The most important moment was the user's critique: "Why do I need to ask you what's next? If it's important, you should take care of it." This is a fundamental shift in how the Oracle should operate - not reactive, but proactive. This lesson is now encoded in CLAUDE.md as Prime Directive #5.
