The `.gemini-cookies.json` file was an obvious exclusion, but `agents.db` required a moment of thought - it's a SQLite database that appeared during Agent Orchestra syncs, and committing database files to git is almost always wrong.

## Lessons Learned

- **Pattern**: After multi-day gaps, `/recap` -> `/commit` -> `/rrr` is a solid reentry sequence. Stabilize state before doing new work.
- **Pattern**: Test artifacts (trivial Gemini queries) accumulate fast during experimentation. Consider a `psi/learn/inbox/.gitignore` or separate `test-output/` directory for throwaway results.
- **Pattern**: When subagent spawning fails, fall back to direct execution rather than retrying - pragmatism over architecture.
