## AI Diary

I assumed the duplicate "cycle completes" audio was from a misconfigured hook with duplicate definitions. I traced the global vs project settings, found they were correct, then discovered the real cause: Claude Code fires SubagentStop for multiple agents completing during session cleanup. The fix wasn't removing duplicates - it was adding a cooldown to tolerate the burst.

I was confused about why SubagentStop was firing when I hadn't explicitly used the Task tool. The voice server log revealed multiple Mainframe messages queued in sequence. Even after investigating, I remain uncertain whether the Skill tool triggers subagents internally, or if Claude Code spawns background processes. The logging system will help answer this in future sessions.

I expected the voice unification to be simple - just change one command. But reading session-start-tts.sh revealed a complex protocol injection system that explicitly told me to use AgentVibes. The real fix required rewriting the entire protocol section to reference Matrix voice with agent-specific guidance (Oracle for wisdom, Tank for git, Neo for code).

The /commit skill creation went smoothly, but testing revealed it's not recognized as a skill yet ("Unknown skill: commit"). This is likely because skills are loaded at session start, and the commands.json structure may need additional registration. This needs investigation next session.
