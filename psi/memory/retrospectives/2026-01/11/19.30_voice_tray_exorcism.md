# Retrospective: Voice Tray Exorcism

**Date**: 2026-01-11 (Saturday)
**Time**: ~19:15 - 19:30
**Duration**: ~15 minutes
**Focus**: Diagnosing and eliminating the "strange voice" anomaly

---

## Executive Summary

User reported hearing a "strange voice" that wasn't appearing in the Matrix voice logs. Through systematic investigation, discovered a global Claude hook (`~/.claude/settings.json`) was running a separate TTS system ("Oracle Voice Tray") that read Claude's text responses aloud using macOS voices. Disabled the rogue system to unify voice output under Matrix control.

---

## What We Did

### 1. Voice Server Restart
- **Problem**: Voice logging changes from previous session weren't active
- **Cause**: Voice server (PID 74939) started Saturday 2AM, before logging code added
- **Fix**: Killed old server, restarted with new code (PID 50790)
- **Result**: Logs now writing to `psi/memory/logs/voice/voice_server.log`

### 2. Strange Voice Investigation
- **Symptom**: User heard voice saying Claude's text responses
- **NOT in logs**: Matrix voice_server.log showed only expected voices (Tank, Mainframe)
- **Clue**: Voice spoke text I wrote but never called voice_module.sh for

### 3. Root Cause Discovery
- **Found**: Global `~/.claude/settings.json` had a `Stop` hook
- **Hook**: `/Users/jarkius/workspace/ai-workshop/01-oracle-voice-tray/scripts/voice-tray-notify.sh`
- **Behavior**: On every Claude response completion, reads transcript and speaks via macOS TTS
- **Voices**: Samantha, Daniel, Karen, Rishi (macOS voices, not Piper)

### 4. Exorcism
- **Action**: Removed `Stop` hook from `~/.claude/settings.json`
- **Before**: `"hooks": { "Stop": [...] }`
- **After**: `"hooks": {}`
- **Result**: Only Matrix voices (Piper) now active

---

## Key Discovery

Two TTS systems were running in parallel:

| System | Trigger | Voices | Logged |
|--------|---------|--------|--------|
| Matrix Voice | Manual `voice_module.sh` calls | Piper (Oracle, Tank, etc.) | Yes |
| Oracle Voice Tray | Global `Stop` hook (every response) | macOS (Samantha, etc.) | No |

The "strange voice" was Oracle Voice Tray - completely separate infrastructure that was never integrated with Matrix logging.
