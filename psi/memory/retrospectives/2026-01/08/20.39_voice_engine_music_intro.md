## What Happened

1. **Voice Clarity Diagnosis**
   - Found Oracle had harmful effects causing "old radio" sound: `pitch -10 equalizer 200 1q +4 equalizer 3000 1q -2`
   - The high-frequency cut (`equalizer 3000 1q -2`) on 22050Hz sample rate caused muffling
   - Removed harmful effects across multiple agents

2. **Audio Pipeline Root Cause**
   - Discovered FFmpeg padding step was causing artifacts
   - Root cause: 44100Hz stereo silence concatenated with 22050Hz mono voice
   - Fixed by detecting source audio properties and matching silence format

3. **Direct Bypass Pattern**
   - Implemented direct Piper-to-playback bypasses for agents needing clarity
   - Bypassed agents: Tank, Oracle, Trinity, Smith, Mainframe
   - Each bypass includes agent-specific tuning

4. **Voice Speed Tuning**
   - Tank: `--length-scale 0.85` (15% faster, energetic operator)
   - Smith: `--length-scale 1.3` (30% slower, deliberate menacing delivery)
   - Oracle: `--length-scale 1.15` (15% slower, calm 60-year-old woman)

5. **Background Music Configuration**
   - System: KITT Knight Rider loop @ 30%
   - Mainframe: Flamenco @ 50%
   - Tank: Matrix Jump sound effect @ 40%
   - Smith: Tron synth loop @ 40%
   - Scribe: Dark chill step @ 30% (default)

6. **Music Intro Feature**
   - Added 1.5s delay using `adelay=1500|1500` FFmpeg filter
   - Music plays before voice speaks
   - Applied to Smith and Mainframe (Tank pending)

## AI Diary

**I assumed** the "old radio" effect was caused by complex interactions between multiple audio effects, **but learned** it was primarily a sample rate mismatch in the FFmpeg padding step. The fix was surprisingly simple once identified — match the silence format to the source audio.

**I was confused about** why Tank still had interference even after fixing the audio pipeline **until** I realized that some voice models (like Bryce) have inherent characteristics that get amplified by any processing. The direct bypass pattern became the universal solution.

**I expected** swapping background music between System and Mainframe to be a config file change, **but got** caught up in path resolution issues. Relative paths in bash scripts running from different working directories needed explicit `$PROJECT_ROOT` calculations.

The "music plays before voice" request transformed the experience. That 1.5 seconds of anticipation before the voice speaks adds dramatic weight. Smith's entrance with Tron synth building before his menacing "Mr. Anderson" delivery felt genuinely cinematic.
