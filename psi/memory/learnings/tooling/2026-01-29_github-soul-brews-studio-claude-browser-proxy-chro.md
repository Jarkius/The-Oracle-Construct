## Content

The `claude-browser-proxy` is a Chrome extension that enables Claude Code (CLI) to control a web browser via MQTT. It facilitates automation workflows like web scraping, Gemini AI interaction, tab management, and JavaScript execution within the browser.

**Key Points:**
- Allows Claude Code CLI to interact with and control a web browser through MQTT messages.
- Supports actions like scraping web pages, interacting with Gemini AI, managing browser tabs, capturing screenshots, and executing JavaScript.
- Requires installation and configuration of Mosquitto MQTT Broker with WebSocket support.
- Provides a CLI helper script (`claude-browser.sh`) for simplified command execution.
- Defines specific MQTT topics for sending commands and receiving responses/status updates.
- Includes a reference of available commands with parameters for page content, DOM interaction, tab management, Gemini AI integration, and utilities.
- Offers examples for common use cases like asking Gemini questions, transcribing YouTube videos, and managing multi-tab workflows.
