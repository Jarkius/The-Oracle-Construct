What is Docker?

At its core, Docker is a platform designed to help developers build, share, and run applications by using containers.

Think of it as a way to package up an application with all of the parts it needs—such as libraries and other dependencies—and ship it all out as one package. This ensures that the application runs the same way on any machine, regardless of the customized settings that machine might have.
