## Getting Started & Installation

Before you begin, ensure you have Node.js installed, as it is the most reliable way to set up the CLI across different operating systems.

- **Install via npm:** `npm install -g @anthropic-ai/claude-code` [[01:05](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=65)]

- **Initial Setup:** Run the command `claude` to start the setup wizard. You will need to sign in to your Anthropic account and choose your UI preferences (e.g., Dark Mode) [[01:13](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=73)].

- **Trusting Directories:** When you first run Claude in a project folder, it will ask to trust the directory. Press 1 to allow it to access your files [[02:07](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=127)].

## Essential Commands & Modes

Claude Code operates in different "modes" that change how it interacts with your codebase.

- **Plan Mode:** Hold Shift + Tab until you see "Plan Mode" in the bottom left. In this mode, Claude will only reason about the task and ask clarifying questions rather than writing code immediately [[03:15](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=195)].

- **YOLO Mode:** Use the command `claude --dangerously-skip-permissions` to enable YOLO mode. This allows Claude to run commands and edit files without asking for manual approval each time [[12:14](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=734)].

- **Clear History:** Type `/clear` to wipe the current conversation history. This is crucial for freeing up context when switching to a new, unrelated task [[08:15](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=495)].

- **Initialize Config:** Use `/init` to set up basic configuration files for the project [[09:21](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=561)].

## Key Strategies for Beginners

To get the most out of the CLI, treat it like a senior engineer rather than a basic chatbot.

- **Use a `CLAUDE.md` File:** This is the "onboarding" file for the AI. Create a file named `CLAUDE.md` in your root directory to define your tech stack, project structure, and coding standards. Claude reads this at the start of every session [[08:34](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=514)].

- **Progressive Disclosure:** Instead of one giant instruction file, use `CLAUDE.md` as an index that points to other specialized markdown files like `architecture.md` or `testing_standards.md` [[09:46](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=586)].

- **Commit Early and Often:** Always commit your work before letting Claude perform a major bug fix or refactor. This makes it easy to revert if the AI introduces regressions [[07:33](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=453)].

- **The "Three Options" Prompt:** When making architectural changes, ask Claude to "provide three options to move forward." This prevents it from picking the first (and potentially incorrect) solution it thinks of [[12:55](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=775)].

## Visual Hierarchy & Workflow

1. **Explore:** Let Claude look at the files first.
2. **Plan:** Enter Plan Mode to discuss the implementation.
3. **Execute:** Switch to normal or YOLO mode to write the code.
4. **Review:** Manually check the diffs and run your test suite [[12:40](http://www.youtube.com/watch?v=eMZmDH3T2bY&t=760)].
