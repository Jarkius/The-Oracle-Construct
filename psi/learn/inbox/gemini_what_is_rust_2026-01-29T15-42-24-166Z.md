What is Rust?

Rust is a multi-paradigm, high-level, general-purpose programming language designed for performance and safety, particularly safe concurrency. It was originally developed at Mozilla Research and has consistently topped developer satisfaction surveys because it solves long-standing frustrations found in older languages like C++.
