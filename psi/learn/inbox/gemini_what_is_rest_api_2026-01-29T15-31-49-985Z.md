What is REST API?

## Response

A REST API (Representational State Transfer) is a set of rules that allows two software applications to communicate with each other over the internet. It is the "middleman" that allows a client (like your phone or a web browser) to request data from a server.

### How It Works

The communication usually follows a simple Request-Response cycle.

The Client sends an HTTP request to a specific URL (an endpoint).

The Server receives the request, processes it (fetches data from a database), and sends back a response.

The Response is typically in JSON format, which is easy for both humans and machines to read.

The Core Components

To make a REST call, you need four main things:

Endpoint: The URL you are calling (e.g., https://api.example.com/users).

Method (Verb): The action you want to perform.

Header: Metadata about the request (e.g., "I'm sending JSON" or "Here is my password").

Body: The actual data you are sending (usually for creating or updating things).

### Common HTTP Methods (CRUD)

REST uses standard HTTP methods to define what action should be taken:

Method	Action	Purpose
GET	Read	Retrieve data (e.g., get a list of products).
POST	Create	Send new data to the server (e.g., create a new account).
PUT	Update	Replace existing data entirely.
PATCH	Update	Modify a small part of existing data.
DELETE	Delete	Remove data from the server.
### Why use REST?

Statelessness: The server doesn't "remember" previous requests. Each request must contain all the information needed to understand it. This makes the system scalable.

Flexibility: Since it returns data (like JSON) rather than a formatted webpage, the same API can power a website, an iPhone app, and an Android app simultaneously.

Standardization: Because it uses standard HTTP, almost every programming language in the world supports it out of the box.

Why? By separating the user interface (the client) from the data storage (the server), developers can update the look of an app without breaking the backend, and vice versa.
