What is GraphQL?

GraphQL is a query language for APIs and a runtime for fulfilling those queries with your existing data. It was developed by Facebook in 2012 and released as an open-source project in 2015.

Unlike REST, which uses multiple endpoints to return fixed data structures, GraphQL allows a client to request exactly what it needs and nothing more. This makes it highly efficient, especially for mobile applications or complex frontends where bandwidth and performance are critical.

Key Concepts

The Schema: A blueprint that defines the data available on the server and how a client can request it. It acts as a contract between the frontend and backend.
